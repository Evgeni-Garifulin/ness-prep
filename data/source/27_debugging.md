# 27. Debugging задачи

1. Компонент бесконечно re-render'ится — найди причину.
2. useEffect вызывается бесконечно — исправь.
3. Input лагает при фильтрации большого списка — исправь.
4. WebSocket UI фризит страницу — исправь.
5. Старая котировка перетирает новую — исправь.
6. После быстрого поиска показываются результаты старого запроса — исправь.
7. Memory leak после ухода со страницы — найди.
8. Modal ломает keyboard navigation — исправь.
9. Dropdown недоступен для screen reader — исправь.
10. Table теряет focus при sort — исправь.
11. React key bug ломает список — исправь.
12. Context вызывает re-render всего приложения — исправь.
13. useMemo не помогает performance — объясни и исправь.
14. Bundle внезапно вырос на 500KB — найди причину.
15. Playwright test flaky — найди причину.
16. Hydration mismatch — найди причину.
17. Ошибка появляется только в production build — расследуй.
18. CORS request падает — объясни возможные причины.
19. XSS vulnerability в preview HTML — исправь.
20. Race condition в token refresh — исправь.
